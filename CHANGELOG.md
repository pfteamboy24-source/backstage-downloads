# Backstage release history

Backstage is still prerelease software. Each release keeps the complete app and adds to the work listed below.

## Preview 13 — Final Preview (September 11, 2026)

- Added a scoped HTTP control API for Bitfocus Companion. Administrators can create or revoke a dedicated token without exposing the Admin PIN.
- Added live-service selection, person publish/show controls, display blackout and restore, layout activation, status reads, and ProPresenter reconnect actions.
- Added a ready-to-import Generic HTTP Companion reference page and API documentation.
- Added an in-app Help & how-to page covering first setup, headless Pi PIN creation, screens, Planning Center, updates, backups, and Companion.
- Combined production screen addresses into one compact section that uses the host's network address.
- Simplified release packaging so installers use the app's single version source and clean staging folders before each build.

## Preview 12 — Team displays and access controls (September 10, 2026)

- Added separate Admin and Team PIN roles with server-enforced access boundaries.
- Added up to 12 named, team-filtered service display outputs with readable stable addresses and independent live layouts.
- Added connected-display startup options for Windows, macOS, Linux, and Raspberry Pi hosts.
- Renamed the people directory from Musicians to Teams and generalized drum kits into reusable fixed setups.
- Imported Planning Center team names and memberships, grouped lineup review by team, and improved plan selection.
- Added read-only service history, automatic removal of declined published people, setup deletion, and clearer update status.

## Preview 11 — Display Builder (September 9, 2026)

- Added a customizable 1920 × 1080 service display with drag, resize, layering, draft preview, and Make live.
- Added slide text, timers, clocks, messages, screen previews, web content, and lineup items.
- Added headless Raspberry Pi first-PIN instructions.
- Added safe equipment editing and deletion.

## Preview 10 — Scheduling status and Pi guidance (September 9, 2026)

- Corrected Planning Center confirmation refresh.
- Blocked assignment publication for declined people and improved compact status placement.
- Expanded Raspberry Pi installation help for systems that open a package as an archive.

## Preview 9 — Lineup preparation (September 8, 2026)

- Put equipment assignments first in the service workflow and added accurate backstage card previews.
- Added independent service times and optional Planning Center lineup review.
- Restricted update installation controls to the Backstage host.

## Previews 5–8 — Display and production workflow (September 7–8, 2026)

- Added the ProPresenter StageDisplay web overlay workflow and clearer NDI/display guidance.
- Added a compact FOH lineup layout and refined the backstage screen modes.
- Improved the browser-based production display experience.

## Preview 4 — Public updates (September 7, 2026)

- Moved installers and update checks to the public downloads repository.
- Removed the need for a GitHub account or access token to install and update Backstage.

## Preview 3 — Backup import (September 7, 2026)

- Added backup preview, explicit replacement confirmation, a recovery export, and protection against concurrent edits.
- Preserved host PIN and connection credentials during restore.

## Preview 2 — Network addresses (September 7, 2026)

- Added host and display addresses to the sidebar with copy controls and automatic refresh.

## Preview 1 — Volunteer preview (September 7, 2026)

- Added Windows x64 and Raspberry Pi arm64 installers with bundled runtimes and beginner guides.
- Established local service lineups, equipment assignments, Planning Center import, backstage publication, and a display-only screen.
